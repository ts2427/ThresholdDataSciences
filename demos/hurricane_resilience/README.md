# When the Network Goes Dark: moved

The code and data for *When the Network Goes Dark*
(https://thresholddatasciences.com/analysis/when-the-network-goes-dark/) now live in their own repository:

**https://github.com/ts2427/when-the-network-goes-dark-data**

It holds every input (with source, URL, retrieval time and SHA-256), the pipeline, the published panel and
`results.json`, and a one-command rebuild that is tested against the published files. It is archived on Zenodo:

- Version 3.1.0, which produced the numbers on the page: https://doi.org/10.5281/zenodo.24534469
- All versions (resolves to the latest): https://doi.org/10.5281/zenodo.24477809

The earlier snapshot that was here is in this repository's git history.
